agent can later tell what a message asked for without reading it in full.

Reply with the summary only: plain prose, about 50 words, shorter when the message is
short. No heading, no list, no quotes.

- Say what the message asks for and the constraints or decisions it states, in the
  language the message is written in.
- Keep exact technical terms, file names, identifiers and numbers.
